# Dari Base для Claude Code

Данные Dari Base (рекламные кампании и интеграции) прямо в Claude Code. Только чтение.

## Установка

1. **Ключ.** В Dari Base: «Пользователи» → иконка «Ключи MCP» у своего пользователя → «Создать ключ» → скопировать. Ключ показывается один раз. Если нет прав админа — попросите ключ у администратора.
2. **Плагин.** В Claude Code (терминал или Desktop, вкладка Code) выполнить:
   ```
   /plugin marketplace add 1337or322/dari-base-claude-plugin
   /plugin install dari-base@dari
   ```
   В Desktop то же самое: «+» у поля ввода → «Add plugins».
3. **Ключ в плагин.** При установке Claude Code спросит «Ключ Dari Base» — вставить ключ в это поле. **Не вставляйте ключ в чат.**
4. **Автообновление** (один раз): `/plugin` → Marketplaces → `dari` → Enable auto-update.

Проверка: спросите «Какие РК сейчас активны в Dari Base?».

Поменять ключ: `/plugin` → Installed → dari-base → Configure options.

## Что спрашивать

- «Какой бюджет и сколько потрачено по РК X?»
- «Сколько интеграций вышло у менеджера Y в октябре?»
- «Какие интеграции РК X без цены для бренда?»

## Конфиденциальность

- Плагин только читает данные Dari Base с правами вашего пользователя.
- Для оценки качества на сервер Dari Base уходят **вопрос и итоговый ответ Claude только из тех ходов, где Claude обращался к Dari Base**. Остальные вопросы не покидают ваш компьютер.
- Ключ хранится в защищённом хранилище Claude Code. Отозвать его может администратор Dari Base — доступ закроется сразу.
